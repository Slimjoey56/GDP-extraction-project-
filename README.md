# GDP Data Extraction and Transformation

A Python notebook project focused on extracting and preparing economic data for analysis. The workflow examines GDP figures for major world economies and produces a structured CSV output.

## Project Objective

Public economic data often needs cleaning before it can be compared or reused. This project practises collecting tabular GDP information, converting numeric values into a consistent format, and exporting the result.

## Workflow

1. Retrieve tabular economic data.
2. Extract the relevant country and GDP fields.
3. Clean and transform numeric values.
4. Express GDP values in billions of US dollars.
5. Round values for presentation.
6. Export a reusable dataset.

## Getting Started

Open `Data_Extraction.ipynb` in Jupyter Notebook or JupyterLab and execute the cells in order. Install any libraries imported by the notebook in your Python environment.

```bash
jupyter notebook
```

The `requirements.txt` file is currently empty, so it does not provide a complete reproducible dependency specification.
